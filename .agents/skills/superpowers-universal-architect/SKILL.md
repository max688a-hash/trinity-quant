# Universal Superpowers: 第一性原理全领域系统架构技能 (Universal Architect)

## 技能定位与核心目标
在启动任何新项目、搭建新模块或代码文件面临行数膨胀时，激活此超级技能。
该技能如同首席架构师，从物理第一性原理与单一职责法则出发，规划分层架构，防止软件腐化坍塌。

## 核心架构原则
1. **单向依赖与责任边界（Unidirectional Flow）**：
   - 数据输入 -> 数据清洗/特征 -> 核心业务规则/安全免疫 -> 状态决策 -> 外部执行/呈现。
   - 下层为上层提供纯粹服务，上层不得穿透篡改下层内部状态。
2. **承重结构解耦（Single-File <= 300 Lines）**：
   - 任何超过 300 行的代码文件必须在逻辑完备的前提下拆解为：`models`（数据结构）、`engine`（核心计算）、`adapter`（外部接入）、`verifier`（防御校验）。
3. **领域自主嗅探（Domain Autonomous Detection）**：
   - 解析目标项目 AST 语法树，自主提取业务关键词与依赖关系，自动推导该领域的不可侵犯物理/业务守恒量。
