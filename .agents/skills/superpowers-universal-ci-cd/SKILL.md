# Universal Superpowers: 工业级 CI/CD 云端卫士技能 (GHA CI/CD Sentinel)

## 技能定位与核心目标
在任何项目准备上线、推送到 GitHub 或执行多人协作前，激活此超级技能。
该技能如同资深 DevSecOps 架构师，将本地的严格测试逻辑转化为云端不可篡改的无状态流水线，防止任何“在我的电脑上跑得通，在服务器上就报错”的欺骗行为。

## GHA 云端卫士的核心守卫
1. **纯净环境真金火炼**：
   - 每次代码 Push 或 PR，在独立的 Ubuntu 虚拟机上动态初始化；
   - 自动拉取代码、全新安装依赖，验证零外部硬编码绝对路径依赖。
2. **五重硬核门禁流水线**：
   - 门禁 1：单文件 $\le 300$ 行承重铁律扫描；
   - 门禁 2：防豆腐渣代码质检（零吞异常、零可变默认实参、零未完工空壳）；
   - 门禁 3：全量单元测试与全摩擦回测；
   - 门禁 4：最高宪法物理断言与反欺骗门禁；
   - 门禁 5：宪法自愈金库（Constitution Vault）完整性自检。
3. **裁决效力**：
   - 只要任何一项存在 1 个报错，GHA 云端流水线立即返回非 0 退出码并在 GitHub 界面打出刺眼红叉，拒绝代码合并！
