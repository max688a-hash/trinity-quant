# Superpowers: 黑天鹅极端市场对偶对抗打击技能 (Adversarial Stress Superpower)

## 技能定位与核心目标
当评估任何量化策略、调优参数或分配实盘资金前，激活此超级技能。
该技能充当一个冷酷、无情的“恶意对抗审查者（Adversarial Auditor）”，其唯一的使命就是在历史 20 年全样本与 5 大黑天鹅极端市场中寻找让策略穿仓爆仓的致命死穴。

## 极端打靶情景库
1. **2008 年全球次贷危机流动性海啸**：
   - 全球权益资产腰斩、基差大幅贴水、大宗商品暴跌、金融机构对手方流动性违约挤兑；
2. **2015 年 A 股千股跌停与流动性枯竭**：
   - 连续多日无量跌停、物理流动性锁死无法平仓、融资盘杠杆踩踏爆仓；
3. **2020 年 3 月全球流动性闪崩与美股四次熔断**：
   - 波动率指数 VIX 飙升至历史高位、大宗商品负油价极端脱锚；
4. **单边剧烈贴水与极端滑点冲击**：
   - 瞬时 5% 开盘跳空缺口、盘口虚假撤单、印花税与佣金翻倍极限挤压。

## 执行工作流
1. **运行黑天鹅防爆压力打靶**：
   ```bash
   .venv/bin/python3 main.py --stress
   ```
2. **审查核心硬性指标**：
   - **极端情景最大受控回撤**：必须 $\le 15\%$（严禁穿仓击穿底层资金）；
   - **99% 极端在险价值（CVaR 99%）**：测算最差 1% 交易日平均极端损失期望；
   - **对偶博弈判定**：任何一个情景出现防御穿透或未触发止损熔断，立即出具 `[FAIL 存在穿透]` 红牌并剥夺实盘资金分配权！
